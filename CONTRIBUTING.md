# Contributing to Varterm

Thanks for helping improve Varterm.

## Development setup

1. Fork the repository.
2. Clone your fork and install dependencies:
   - `npm install`
3. Copy envs:
   - `cp .env.example .env.local`
4. Start local dev:
   - `npm run dev`

## Branches and pull requests

- Create a focused branch per change.
- Keep PRs small and reviewable.
- Include a short test plan in the PR description.
- Link related issues when available.

## Code style and checks

- Run `npm run lint`.
- Run `npm test`.
- Keep changes consistent with existing style.

## Commit guidance

- Write clear commit messages in imperative mood.
- Explain why in commit body when context is not obvious.

## Reporting bugs

Please use the bug report template and include:

- Expected behavior
- Actual behavior
- Repro steps
- Browser/OS and logs
