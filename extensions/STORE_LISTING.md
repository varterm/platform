• ⚡ Fast audio generation
• 🔒 Privacy-first - text processed securely, never stored
• 🆓 100% free, no account required

**Voice Options:**
• Cloud voices: Natural-sounding Microsoft neural TTS (Aria, Jenny, Guy, and more)
• Browser voices: Offline playback using your device's built-in speech

**Perfect for:**
• Reading articles and blog posts
• Studying documentation

2. Click the 🔊 button that appears

## VS Code Marketplace

### Name
Varterm TTS - Text to Speech

### Short Description
Read code, documentation, and errors aloud with natural AI voices. Perfect for accessibility and code review.

### Detailed Description
Varterm TTS brings text-to-speech directly into VS Code and Cursor. Read your code, documentation, comments, and error messages aloud with high-quality AI voices.

## Features

**Read Selection** (`Cmd/Ctrl+Shift+R`)
Select any text and hear it spoken aloud. Great for proofreading comments and documentation.

**Read Current Line** (`Cmd/Ctrl+Shift+L`)
Quickly hear the line your cursor is on. Useful for debugging and code review.

**Read Errors & Warnings** (`Cmd/Ctrl+Shift+E`)
Have all current diagnostics read to you. Know what's broken without switching focus.

**Read Entire Document**
Listen to complete files. Perfect for reviewing pull requests or documentation.

## Why Varterm TTS?

- **Accessibility**: Screen reader alternative for developers
- **Multitasking**: Listen while you work on something else
- **Proofreading**: Catch typos by hearing your text
- **Learning**: Better understand code by hearing it explained
- **Focus**: Rest your eyes, keep coding

## Configuration

- `varterm.voice` - Choose your preferred voice
- `varterm.rate` - Adjust speech speed (0.5x - 2x)
- `varterm.stripMarkdown` - Clean up markdown before speaking
- `varterm.autoReadErrors` - Automatically announce new errors
