# Marketing Strategy Docs

This folder is the source of truth for Varterm marketing, GTM, and SEO direction.

## Documents

- `current-state-marketing-gtm-seo.md`  
  Audit of current live messaging and implementation across the site.

- `marketing-strategy-canonical.md`  
  Approved strategy to guide copy, page updates, SEO content, and outreach.

- `marketing-sync-matrix.md`  
  Page-by-page and asset-by-asset alignment tracker against the approved strategy.

- `outreach-playbook.md`  
  Partner and customer messaging templates, including archive/library-style outreach.

## Working rule

Before changing homepage, extensions, SEO pages, or launch copy:
1. Confirm updates align with `marketing-strategy-canonical.md`.
2. Update `marketing-sync-matrix.md` to reflect new status.
3. If positioning changes, update this folder in the same PR.
