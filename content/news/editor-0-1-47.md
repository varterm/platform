**Varterm TTS 0.1.47** is the current editor build. Install from [Open VSX](https://open-vsx.org/extension/Varterm/varterm-cursor) (Cursor) or the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Varterm.varterm-cursor). The `.vsix` is on [GitHub Release v0.1.47](https://github.com/varterm/extensions/releases/tag/v0.1.47).

- **Highlight to listen.** Select text and click the status bar icon, or right-click **Read Selection Aloud**. Nothing is copied.
- **Speed and voice.** The `1×` chip opens 0.75×–2× and the voice list. Click the speaker on a voice for a short preview. Enter only saves that voice.
- **Agent Auto-read** still speaks finished replies. After a clipboard or paste listen, the next finished reply takes the speaker again.

Setup notes live on the [extensions page](/extensions#editors).
